# A02
1. Proceed to the official Git website: https://git-scm.com/downloads.
2. Pick the correct operating system (Windows, MacOS, or Linux) and download the corresponding installer.
3. Run and complete installer instructions.
4. Download Webstorm from: https://www.jetbrains.com/student/
5. Run the Webstorm installer and complete instructions.
6. Create a GitHub account here: https://github.com/join
7. To connect GitHub to Webstorm, press (Ctrl+Shift+S) and navigate to system preferences.
8. Select Version Control, and then select Git.
9. Click Test to ensure that Webstorm is connected to Git. If Git is installed and connected, you should receive the message: "Git Executed Sucessfully."
10. To add a GitHub password, navigate to system preferences, pick appearance and behavior, then system settings, and then password.
11. To create a repository on GitHub, go to GitHub (https://github.com/) select "Create new repository," make it public, and then finally add the README.file. A repository can also be created in Webstorm through selecting VCS, importing into version control, and then selecting Git Repository.
12. If a repository was already created on GitHub, then import the repository to Webstorm. This can be done through opening Webstorm, selecting VCS, checking out from version control, and picking Git. Then the GitHub repository name and local path can be entered. 
13. To create a Webstorm file, choose file, go to HTML, then HTML5.
14. Make any changes within the Webstorm file, then go to VCS, press Git, and press Commit File (If this is the first commit ever, you will have a dialog box open. Set the Git username and email)
15. To add the project to GitHub, click VCS, import into version control, and then share project on GitHub. You should receive a message: "Successfully shared project on GitHub."
16. Go back to GitHub (https://github.com/), create a file and name it READ.ME.MD. Add some text and commit that text.
17. To commit to Git, make some changes in Webstorm, then press VCS, then Git, add the commit comment, and then commit.
18. To push the change to GitHub, press VCS, then Git, then push. Whatever was changed should appear on GitHub.
